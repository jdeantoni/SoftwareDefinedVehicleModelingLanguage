# SoftwareDefinedVehicleModelingLanguage
a simple DSL for SDV understandable timing Analysis

## Building the plugin

```
npm install
```
to resolve all dependencies

```
yarn
```
to compile.

check the [language README](./packages/language-server/README.md)

## Using
### Analysis dependencies
- CADP toolkit
- IF toolset
- PRISM
- MRTCCSL
    - install in a global switch
    - or specify the path to the switch in the settings
- ninja build system
